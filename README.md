# Herramientas de IA para asociaciones de pacientes

Portal del curso «IA para asociaciones de pacientes» del **Instituto ProPatiens** y la **Cátedra del Paciente de la Universidad Miguel Hernández de Elche**.

Página publicada: https://fborrasumh.github.io/propatiens/

Reúne las cuatro apps del curso, los materiales de cada sesión, la guía para crear la clave de API y las normas de uso. Disponible en castellano, català, euskara, galego, English y português.

| App | Sesión | Área |
|---|---|---|
| JuntIA | 2 | Comunicación interna |
| DifundIA | 3 | Comunicación externa |
| SubvencIA | 4 | Proyectos de financiación |
| EncuestIA | 5 | Análisis de encuestas |

## Mantenimiento

En `index.html`, el array `APPS` controla las fichas:

- `ready: true` cuando la app esté publicada en `https://fborrasumh.github.io/<id>/` (activa el botón «Abrir app»).
- `doi: "10.5281/zenodo.XXXXXXX"` cuando se acuñe el DOI de concepto en Zenodo.

Los logotipos están en `assets/` (versión blanca para la cabecera oscura).
